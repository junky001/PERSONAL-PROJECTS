# Othoro Mixed Secondary School Website

A website for Othoro Mixed Secondary School, built with HTML, CSS and JavaScript. It gives students, parents and visitors a simple place to learn about the school and how to join it.

## Pages

- **Home (`othoro.html`)**: hero section, school information, photo gallery and a back-to-top button
- **Admissions (`admissions.html`)**: information for prospective students and how to apply

## Features

- Sticky header for easy navigation
- Photo gallery with a lightbox viewer for enlarged images
- Back-to-top button
- Separate stylesheets and scripts for the home and admissions pages

## Built With

- HTML5
- CSS3
- JavaScript
