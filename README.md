# Othoro Mixed Secondary School Website

A website for Othoro Mixed Secondary School, built with HTML, CSS and JavaScript. It gives students, parents and visitors a simple place to learn about the school and how to join it.

## Pages

- **Home (`index.html`)**: hero section, school information, photo gallery and a back-to-top button
- **Admissions (`admissions.html`)**: information for prospective students and how to apply

## Features

- Sticky header for easy navigation
- Photo gallery with a lightbox viewer for enlarged images
- Back-to-top button
- Separate stylesheets and scripts for the home and admissions pages

## Built With

- HTML5
- CSS3
- JavaScript

## Project Structure

```
├── index.html        # Home page
├── othoro.css         # Home page styles
├── othoro.js          # Home page scripts
├── admissions.html    # Admissions page
├── admissions.css     # Admissions page styles
└── othoro_files/      # Images and admissions.js
```

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.

For live reloading, open the folder in VS Code and use the **Go Live** button.
